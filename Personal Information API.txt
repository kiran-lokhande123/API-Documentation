Personal Information API

This API will return personal information including name, address, and number for a partilcar Aadhar number.

Input

Aadhar number: String. The gov issued number.

Output
Name: String: The name of the person.
Address: String: Address of the person.
Phone Number: Number: contact number of the person.

URL

https://www.getmytestinfo.com

Scheme:
{
"Info":{
"name":test"
}
}
