3. Understand what we created
YAML element	Purpose
components	Holds reusable definitions.
schemas	Holds data structures used by the API.
Employee	Name of our data structure.
type: object	Indicates that an employee is represented as an object containing properties.
properties	Defines the individual employee fields.
type: string	Specifies that the field contains text.
format: email	Specifies that the string should follow an email address format.
required	Identifies fields that must be present.

Why do we need a schema?

Imagine we have five API endpoints that return employee information.

Instead of describing all five employee data structures separately, we define the Employee schema once and reference it wherever needed.

That's the benefit of reusable schemas.
