Why do we use GET?
Note that GET is a HTTP method.

HTTP provides different methods to tell an API what operation we want to perform.

For our project:
Method	Meaning
GET	Retrieve information
POST	Create information
PUT	Update information
DELETE	Delete information

Here, we use GET because we only want to retrieve employee records. We aren't creating or modifying anything.
