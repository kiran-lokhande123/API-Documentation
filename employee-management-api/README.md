# Employee Management API

## Project Overview

This is a sample API documentation project created to demonstrate hands-on experience with OpenAPI, YAML, and Swagger.

The fictional Employee Management API allows applications to retrieve employee information and create new employee records.

## API Operations

| HTTP Method | Endpoint | Description |
|---|---|---|
| GET | `/employees` | Retrieve all employees |
| GET | `/employees/{employeeId}` | Retrieve an employee by ID |
| POST | `/employees` | Create a new employee |

## Documentation Features
